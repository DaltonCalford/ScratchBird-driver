# ScratchBird Beta Release Bundles

This directory contains pre-release (beta) artifact bundles.

Current bundles:

- `0.1.0-dbeaver.beta.1` - DBeaver plugin packaging + JDBC artifacts for recursive-schema integration testing.
- `0.1.0-jdbc.beta.1` - JDBC-only beta bundle for driver evaluation (no human QA sign-off yet).

Each bundle includes:

- installable artifacts
- SHA256 checksums
- release notes with test/readiness caveats
