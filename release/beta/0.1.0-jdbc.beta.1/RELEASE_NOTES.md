# Release Notes: 0.1.0-jdbc.beta.1

This beta is a JDBC-only cut intended for controlled evaluation.

Included in this beta:

- ScratchBird JDBC driver jar
- ScratchBird JDBC sources jar
- Recursive-schema metadata compatibility flag support:
  - metadataExpandSchemaParents=true

Risk level:

- This is a pre-release beta package.
- No human exploratory QA sign-off has been completed yet.

Recommended use:

- Evaluation and integration testing in controlled environments.
- Not recommended yet as a fully production-certified release.
