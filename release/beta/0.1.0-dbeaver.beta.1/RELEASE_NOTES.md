# Release Notes: 0.1.0-dbeaver.beta.1

This beta provides the ScratchBird DBeaver extension packaging for stock DBeaver installs plus the JDBC metadata compatibility path for recursive schemas.

Included in this beta:

- Standalone p2 update-site package for DBeaver plugin installation.
- ScratchBird JDBC artifacts for local driver manager wiring.
- Recursive schema tree support via plugin metadata model.
- Optional JDBC metadata parent-expansion flag:
  - metadataExpandSchemaParents=true

Risk level:

- This is a pre-release beta package.
- No human exploratory QA sign-off has been completed yet.

Recommended use:

- Evaluation and controlled pilot environments.
- Not recommended yet as a fully production-certified release.
