# ScratchBird Drivers Wiki

Official native drivers for the ScratchBird database engine. All drivers in this
repo target the ScratchBird wire protocol (SBWP v1.1) and require TLS 1.3.

## Quick Links

- Repo: https://github.com/DaltonCalford/ScratchBird-driver
- Driver documentation: https://github.com/DaltonCalford/ScratchBird-driver/tree/main/docs
- Specifications: https://github.com/DaltonCalford/ScratchBird-driver/tree/main/docs/specifications
- Conformance fixtures: https://github.com/DaltonCalford/ScratchBird-driver/tree/main/docs/fixtures

## Supported Drivers

See the full list and per-driver links on the [Drivers](Drivers.md) page.

## Status

All drivers are in active development. SBWP v1.1 is the target protocol for
native connections on port 3092.
