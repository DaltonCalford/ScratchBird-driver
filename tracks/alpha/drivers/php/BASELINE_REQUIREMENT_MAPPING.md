## Notes on current status

- CONN: Core DSN parse, TCP/TLS connect, startup/auth payload handling, and manager-proxy negotiation exist with targeted unit tests. Status remains `Partial` because live auth-mode matrix and manager-proxy integration coverage are still thin in lane-local tests.
- TXN: Begin/commit/rollback/savepoint paths now have dedicated lane-local transaction guard and lifecycle tests; status remains `Partial` because integration coverage across server-side transaction semantics is still limited.
- META: Lane metadata now includes executable collection routing through `Connection::queryMetadata(...)`/`getSchema(...)` with extended family coverage (catalog/key/privilege/type/routine), alias normalization, and driver-side restriction filtering (alias-based matching, null matching, unknown-key ignore) with wire-level execution tests. Status remains `Partial` pending live integration assertions.
- TYPE: Codec covers many scalar and advanced OIDs, and lane tests now validate representative encode/decode fidelity (json/jsonb, uuid, money/numeric, range, composite, unknown-type heuristics); full per-oid fidelity matrix remains open.
- EXEC: Lane execution parity now includes `nativeSql` and `nativeCallableSql`, callable execution (`call(...)`), first-class batch summaries (`executeBatch/queryBatch`), first-class multi-result summaries (`queryMulti/executeMulti`), statement-level multi-result traversal (`nextRowset/nextset`), and generated-key retrieval (`executeWithGeneratedKeys` / `getGeneratedKeys`) with wire-fixture coverage plus env-gated integration checks for multi-result/batch/call/rowset traversal. Status remains `Partial` due broader advanced execution stress coverage and limited non-gated live depth.
- ERR: SQLSTATE-to-exception mapping, wire error detail/hint propagation, and `lastError` recording behavior now have dedicated lane-local tests (`tests/ErrorsTest.php`) in addition to execution-path error-info assertions.
