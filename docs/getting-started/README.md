# Getting Started

Installation and first-connection guidance for the active Beta 1 driver,
tooling, and adapter lanes.

For `planned_beta1` lanes, these pages are implementation-ready guidance rather
than proof of a shipped package. Use the lane authority index and remaining-work
reports to distinguish implemented lanes from newly specified expansion lanes.
