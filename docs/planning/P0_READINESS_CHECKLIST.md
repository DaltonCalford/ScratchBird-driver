# P0 Readiness Checklist (Derived from `RELEASE_TARGETS.md`)

This checklist captures the P0 (Alpha) release targets in actionable form.
Use it to track readiness across core drivers and CLI tools.

## P0 Checklist

- [ ] SBWP v1.1 baseline across core drivers and CLI.
- [ ] TLS enforced; binary-only parameters (no plaintext fallback).
- [ ] Full type matrix encode/decode implemented.
- [ ] Metadata helpers wired to sys.* contract.
- [ ] Conformance harness coverage for baseline protocol + types.
- [ ] Core server ops viable for testing (create/query/transactions).
- [ ] Developer docs/specs prioritized over general docs.
